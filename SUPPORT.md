# Support

## Questions and usage help

Open a **Feedback** or **Question** issue with:

- version;
- Windows or Linux version;
- what you tried;
- exact error text;
- whether the file is public/open-source.

Do not attach proprietary binaries, PDBs, ROMs or personal data.

## Bugs

Use the **Bug report** form.

## Security

Follow [SECURITY.md](SECURITY.md). Do not open a public issue.

## Commercial support

There is no commercial support contract. Donations are optional and do not
create a support obligation.
