What this app is

A local UI over the scripts in this repository. It does not upload files, does not execute games, and does not turn a GameCube game into a native APK. It analyzes code and patches, and it runs long jobs in the background.

GUIDE

From install to first diff.

Six short paths: inspect a file, compare two builds, open source, compare APKs, PowerPC, and export. Everything runs on this machine.

First run checklist

The dashboard should show ready, Ghidra ready and REA ready. If it does, the engine is installed correctly.

readyGhidraREAPython 3.12
01

Inspect a file

Drop in an EXE, DLL, ELF, Mach-O, APK, IPA, JAR or WASM. You get format, size, hash, capabilities and structure.

Try: pyrogenesis.exe, metroid.elf, app.apk.

02

Compare two Windows builds

Pick Build A and Build B folders with matching PDBs. Release Diff shows matched, changed, removed and added functions.

Use the same build twice as a control. Expected: 100% identical.

03

Go to the source line

Set Source root to the repository that contains source/. Then press Open beside a changed function.

Example: C:\src\0ad maps to source/ps/hotkey.cpp:133.

04

Compare two APKs

APK Diff parses DEX, normalizes instructions, and reports changed, removed and added methods. Use one APK twice as a control.

Native .so libraries are counted but not yet diffed.

05

GameCube / PowerPC

PPC Diff needs an ELF and a Ghidra function CSV for each side. The same ELF twice is a valid control.

This is experimental; it is not a playable port.

06

Export and revisit

Every comparison produces a changed CSV and a full JSON. Jobs are saved across restarts and can be reopened from Jobs.

Downloads are generated locally; nothing is uploaded.

If something fails

  • Not ready: reopen the desktop shortcut; the bundled server may still be starting.
  • PDB missing: Build A and Build B need matching PDB files next to the executables.
  • Source Open does nothing: set Source root to the folder containing source, not to source itself.
  • Port 8765 busy: close the old window, then reopen the shortcut.

What this app does not do

  • It does not run, emulate or play games.
  • It does not turn a GameCube game into an APK.
  • It does not recover original source for closed-source games.
  • APK and iOS code analysis is method-level, not full decompilation.

ABOUT

Local-first, cross-platform.

A responsive web front end to the Reverse Update toolkit. One codebase for Windows, macOS, Linux, Android and iPadOS browsers.

Deployment

  • Desktop: run the server, open the local URL.
  • Tablet / phone: open the LAN URL in the browser and add to home screen.
  • No cloud: files are read from the host filesystem.
  • No native APK: this is a web app; native shells are a later packaging step.

Boundaries

  • Static analysis only; it does not execute game binaries.
  • No DRM, anti-cheat or signature bypass.
  • Ghidra/REA are optional and installed separately.
  • Analysis is not a native port.
