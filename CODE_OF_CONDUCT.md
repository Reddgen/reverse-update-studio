# Code of Conduct

## Expected

- Be direct and technical.
- Critique code and ideas, not people.
- Assume good faith.
- Respect licences and attribution.
- Respect privacy: redact paths, PDBs and personal data.
- Follow the law and the target's EULA.

## Not welcome

- Harassment, threats, doxxing or discrimination.
- Malware, piracy, DRM/anti-cheat bypass or unauthorised access.
- Publishing private data or proprietary binaries.
- Spam, fake issues or inflated claims.

## Enforcement

Maintainers may edit, lock or remove content and may block accounts that violate
this code.

Report conduct issues privately through the repository owner's GitHub profile.
